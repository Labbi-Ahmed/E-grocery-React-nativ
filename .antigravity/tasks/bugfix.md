# Task: Bug Fix

For diagnosing and fixing app issues:

1. **Reproduction:** Clearly map out the steps to reproduce the bug locally.
2. **Identification:** Trace the root cause in the component lifecycle or global state.
3. **Typing Fixes:** Identify if typing mismatches (`any`) caused data issues, and apply strict types to resolve them.
4. **Implementation:** Apply the fix and verify.
5. **Regression Test:** Briefly ensure surrounding related components are not impacted.
