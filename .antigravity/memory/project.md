# Project Overview

**Name:** E-grocery App (African Market Ecommerce App)
**Type:** E-commerce Selling Platform
**Tech Stack:** React Native, Expo, React Navigation

This project is an e-commerce platform focusing on grocery and market products. It includes features like user authentication, categories, searching, product listings, cart management, and reviews. Our goal is to maintain a high-quality, pixel-perfect user interface mapped closely to the provided Figma designs.
